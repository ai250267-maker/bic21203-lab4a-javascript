## Description
This repository contains the solutions for Lab 4a, demonstrating modern client-side JavaScript concepts including DOM manipulation, event handling (`addEventListener`), input validation using conditional statements (`if...else if...else`), and dynamic HTML element generation using `for` loops.

## How to Run Each Question
1. **Question 1 (Interactive Text Changer):** Open `question1/index1.html` in a web browser and click the **Change Message** button to update the paragraph text.
2. **Question 2 (Smart Number Validator):** Open `question2/index2.html` in a web browser, enter a value into the input box, and click **Check** to validate whether the number is lower, higher, or equal to 10.
3. **Question 3 (Dynamic Number Generator):** Open `question3/index3.html` in a web browser and click **Generate** to display a numbered list from 1 to 5 without duplicates.
